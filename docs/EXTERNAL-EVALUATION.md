## Candidate source

The [CSE-CIC-IDS2018 dataset](https://www.unb.ca/cic/datasets/ids-2018.html) is a candidate separate capture. The publisher describes daily data and CICFlowMeter-V3 flow features. The [AWS registry](https://registry.opendata.aws/cse-cic-ids2018/) identifies the public `cse-cic-ids2018` bucket in `ca-central-1`. Its license requires citing the dataset and linking the registry. Dataset availability does not establish exact feature equivalence: header aliases, all 27 definitions, directional conventions, units, labels, missing values and extraction version must be checked against source documentation and sample schema before any scoring. Record unresolved mismatches and block scoring rather than guessing.

This is a separately collected, generated research environment with related tools and scenarios, not proof of generalization to real networks. Select the external capture and evaluation files by an a priori rule before reading model outcomes; keep any schema inspection or adaptation subset distinct from final assessment files. If adaptation uses external labels or scores, reserve a separate capture block untouched by those choices and state what was used.

## Frozen binary models

The selected balanced-subsample models were reproduced and saved under `artifacts/external-evaluation-frozen-binary/`. All 5,937 original and 4,965 corrected validation scores, thresholds and metrics match Experiment 003 exactly before and after reload. Original threshold: `0.014966651761014393`; corrected: `0.004978565719683209`. Source and reference hashes, cohort fingerprints, model hashes, feature units and environment are in the bundle provenance. No new test scoring occurred.

These are binary-only research bundles; `attack_traffic.freeze_binary.load_binary` loads them, while the existing family-model scoring CLI does not. Load only trusted local joblib files: hash checks detect corruption but do not make deserialization safe or authenticate consistently rewritten artifacts. The freeze implementation was subsequently hardened only in its loader; a post-freeze implementation hash snapshot is recorded separately in `artifacts/external-evaluation-freeze-implementation.json`, and is not a hash of the exact fitting-time implementation. Two focused synthetic tests pass. Reproduce into a fresh directory with `freeze_binary_models` using the frozen paired run and Experiment 003 reference.

The preliminary `attack_traffic.external_contract.validate_external_contract` function checks canonical CSV and manifest hashes, exact columns and declared units, label mapping, finite values, unique IDs and matches against one supplied frozen split ledger. Six synthetic tests cover the checker. It rejects a matching feature vector instead of silently filtering it; equal features do not establish identical flows, and the conservative rule may reject legitimate external traffic. Any choice to resolve collisions needs a separately documented policy and population accounting. It does not inspect other training sources unless they are incorporated in the supplied ledger, and declarations alone do not establish correct units, labels, capture independence or a frozen model. Freeze the model and threshold before using the checker on final assessment data, because it parses labels and features even though it does not compute model outcomes.
