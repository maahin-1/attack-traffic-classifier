# PRD requirement review — 5 November 2026

Scope: the offline **Experiment 002 1% capture-day research comparison**, not a production detector, full-data benchmark or independent new assessment. This review checks the recorded implementation against [PRD 01](../PRD-01-attack-traffic-classifier.md) and notes the stronger timing and reproduction limits in [TRD 01](../TRD-01-attack-traffic-classifier.md). It is an evidence review, not an authorization to publish data or a claim that all release gates are closed.

| Requirement | Verdict | Evidence and qualification |
| --- | --- | --- |
| AT-P01: provenance and counts | **Met for the local snapshots, qualified** | Both archive sizes and SHA-256 values match acquisition records and the run manifest. Original source has 3,119,345 CSV records including 288,602 empty padding records; the corrected source inventory contains 2,099,976 rows. The selected-flow audit reconciles 28,234 original and 20,909 corrected inputs to retained, excluded and quarantined dispositions. These local hashes do not independently authenticate ground truth or grant redistribution rights. |
| AT-P02: exclude identifiers and disclose features | **Met for these bundles** | Both trusted local bundles load after metadata/hash verification. Bundle metadata and audit lists agree on 27 ordered feature names; each fitted binary and family estimator reports 27 inputs. All names pass the implemented feature guard and no flag fields appear. The estimators were fitted on arrays, so fitted dimension alone does not independently recover the meaning/order of each input. |
| AT-P03: chronological partitions and class coverage | **Qualified** | All retained rows follow the configured capture-date partitions; no retained feature-duplicate group crosses partitions, and binary support agrees with the inventory. Original AM/PM and timezone remain unknown, so exact UTC event order and identical original/corrected UTC-instant boundaries are **not** established. Conservative uncertainty and quarantine are documented. |
| AT-P04: binary detector and multiclass diagnostic | **Met with explicit seen/unseen limits** | Both model bundles contain binary and family pipelines. All 31 random-forest family-table rows agree with the retained split's training and test supports and seen/unseen flags; absent test families have null detection recall. Unseen families cannot be learned by the closed-set family classifier. |
| AT-P05: compare original and corrected | **Met for an exploratory population comparison** | The [rebuilt report](../artifacts/release-review-rebuilt-20261105/report.md) identifies independently sampled and reconstructed populations and explicitly rejects a label-only causal interpretation. Corrected test data had been examined before the comparison. |
| AT-P06: metrics and support | **Met with statistical limitations** | The saved-score report contains FPR, recall, precision, confusion counts, precision@100 and class support. Test results are DDoS-dominated; rare families and incomplete day coverage limit interpretation. Two test days are insufficient for robust temporal-block comparison intervals. Later [external sensitivity results](EXPERIMENT-007-SENSITIVITY-RESULTS.md) remain descriptive of a consumed capture. |
| AT-P07: rebuild reports | **Met for the tested artifacts, qualified** | A new virtual environment rebuilt the actual saved-score comparison with charts and Parquet. Its `metrics.json`, `metrics.csv`, `per_class.csv` and `comparison.csv` were byte-identical to the earlier rebuilt report. A separate [synthetic smoke test](CLEAN-ENVIRONMENT-SMOKE-2026-11-05.md) checked training and scoring. The test uses the host OS/Python; transitive dependencies are not fully pinned, and no fresh full-data training run was performed. |

## Checks and practical boundaries

The repeatable [review script](../scripts/review_release_20261105.py) produced [machine-readable evidence](../artifacts/release-review-20261105.json). Archive and model-bundle hashes were recomputed; the split ledger was counted directly. Previously recorded real-data saved-model parity covers 8,622 original and 6,990 corrected test rows with zero score difference and identical decisions; this review checked that evidence against test support but did not rerun that scoring. The current-machine full suite previously passed 209 tests and 117 subtests; the new review script itself was exercised successfully on the real saved artifacts.

The source [UNB CICIDS2017 page](https://www.unb.ca/cic/datasets/ids-2017.html) identifies the original files as available to researchers and requests citation of its associated paper. The [CNS2022 download page](https://intrusion-detection.distrinet-research.be/CNS2022/Dataset_Download.html) gives attempted-flow guidance but does not state a redistribution license. Those statements do not establish permission to redistribute either archive or derived records. The local `.gitignore` excludes `data/`, `artifacts/` and model binaries; there is no verified repository status because this workspace has no Git metadata. Review any future publication package separately.

Remaining decisions/work: maintain the original-clock qualification and flag-feature exclusion; verify or avoid dataset/derived-data redistribution; make a reproducible publication package with current documentation and a tested dependency lock if stronger environment repeatability is required. A new independently captured holdout, separately frozen model and threshold, and compatible feature extraction are necessary for a new generalization claim. A fresh full-data benchmark is a separate project goal, not a claim made by this review. No model or threshold was changed.
