# Standard-deviation follow-up fixture

Using the same pinned source and isolated environment as the second extractor
plan, generate two forward UDP packets with payload lengths 4 and 8 bytes,
one second apart. The population standard deviation of [4, 8] is 2 bytes;
the sample standard deviation is sqrt(8), approximately 2.828427 bytes. Record
the candidate's output and distinguish this calculation comparison from a run
of Java CICFlowMeter, which is not available. Do not process real traffic.
